# Directive verbs

## Prompt glossary

`src/lib/marking/prompts.ts` gives these NESA glossary meanings to both the written grader and blind checker.

| Verb        | Meaning used in the prompt                                             |
| ----------- | ---------------------------------------------------------------------- |
| Identify    | Recognise and name.                                                    |
| Outline     | Sketch the main features.                                              |
| Describe    | Provide characteristics and features.                                  |
| Explain     | Relate cause and effect and make relationships evident.                |
| Analyse     | Identify components and their relationships and draw out implications. |
| Assess      | Make a judgement of value, quality, outcomes or results.               |
| Evaluate    | Judge against criteria.                                                |
| Discuss     | Identify issues and provide points for and/or against.                 |
| Compare     | Show similarities and differences.                                     |
| Distinguish | Recognise differences.                                                 |

## Explanation and analysis

When a top-band descriptor demands explain or analyse, the prompt requires an explicit mechanism linking cause and effect and coverage of the main effects. One effect, or effects without their mechanism, describes rather than explains and belongs in the band below.

See [ENGINE](/admin/marking/engine?tab=docs&doc=ENGINE) for the shared band and evidence rules.

## Verb and Analysis tags

**Verb** covers meeting the directive verb; **Analysis** covers cause-and-effect links and judgement. The prompt requires exactly one tag per comment. The server checks the tag enum, not whether the tag fits the advice. See [COMMENT-RULES](/admin/marking/engine?tab=docs&doc=COMMENT-RULES) for the full tags table and prompt-only comment rules.
